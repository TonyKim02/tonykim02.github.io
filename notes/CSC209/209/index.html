Shells

Std output, Std input, and piping

Filesystem

  • Inode: DS that contains information about a file
    • Metadata
    • where it is stored
  • Directory: special type of file that contains directory entries
    • Directory entry: mapping from file name to inode
    • can be nested
    • root directory is at the top of the hierarchy, simply named /

File Permissions

  • 3 levels of user access
    • user: who owns the file
    • groups: users that are associated with
    • other users
  • 3 types of access
TypeFor a fileFor a directory
readView contents of fileAdd/remove files from directory
writeEdit/delete fileAdd/remove files from directory
executeExecute a file"Pass through" directory to access subdirectories
  • Inspect permission using ls -l 
-rwx--x--x 1 liudavid instrs 16880 Jan 4 13:10 hello  
-rw------- 1 liudavid instrs 166 Jan 4 12:21 hello.c
  • change permission of file using chmod MODE FILE ...
    • Three numbers between 0 and 7, for user/group/other
      • Each number represents three bits $(b_{0}b_{1}b_{2})_{2}$ where each bit is r/w/x
      • Ex: chmod 741 hello
    • other way to do it is <u/g/o><+/-><r/w/x>
      • Ex:chmod u+x hello or chmod g-w hello

Copying Strings

  • strcpy(char* s1, char* s2)
    • copies the characters from string s2 into the beginning of string s1
    • s2 is required to be string
      • string literal or char array with null term
    • strncpy(char *s1, char*s2, int n)
      • n indicates maximum parameter
      • max num n including null terminator
      • to be safe, add the null termaintor add the end
#include <stdio.h>
#include <string.h>

int main() {
    char s1[5];
    char s2[32] = "University of";

    // This is unsafe because s1 may not have enough space
    // to hold all the characters copied from s2.
    //strcpy(s1, s2);

    // This doesn't necessarily null-terminate s1 if there isn't space.
    strncpy(s1, s2, sizeof(s1));
    // So we explicitly terminate s1 by setting a null-terminator.
    s1[4] = '\0';

    printf("%s\n", s1);
    printf("%s\n", s2);
    return 0;
}

Searching with Strings

  • char* strchr(const char* s, int c)
    • returns a pointer to the character that was found
    • or null if was not found in the string
  • char *strstr(const char *s1, const char *s2)
    • if s2 is found in s1, returns the pointer to character of s1 that begins the match with s2
#include <stdio.h>
#include <string.h>

int main() {
    char s1[30] = "University of C Programming";
    char *p;

    // find the index of the first 'v'
    p = strchr(s1, 'v');
    if (p == NULL) {
        printf("Character not found\n");
    } else {
        printf("Character found at index %ld\n", p - s1);
    }

    // find the first token (up to the first space)
    p = strchr(s1, ' ');
    if (p != NULL) {
        *p = '\0';
    }
    printf("%s\n", s1);

    return 0;
}

#include <stdio.h>
#include <string.h>

int main() {
    // Note that "struct" is required whenever we declare
    // a variable of a structure type:
    struct student {
        // Members of struct student:
        char first_name[20];
        char last_name[20];
        int year;
        float gpa;
    };

    // good_student is of type "struct student"
    struct student good_student;
  
    // Initialize the members of the struct using dot notation:
    strcpy(good_student.first_name, "Jo");
    strcpy(good_student.last_name, "Smith");
    good_student.year = 2;
    good_student.gpa = 3.2;
  
    // Print the values of good_student's members:
    printf("Name: %s %s\n",
           good_student.first_name, good_student.last_name);
    printf("Year: %d. GPA: %.2f\n", good_student.year, good_student.gpa);
  
    return 0;
}

Using Structs in Functions

  • we know the typical array calls of functions
#include <stdio.h>

/* Changes the value of the 0th element of int array numbers
 * to 80. 
 */
void change(int numbers[]) {
    numbers[0] = 80;
}

int main() {
    int my_array[5];

    my_array[0] = 40;
    change(my_array);

    // The following prints 80 because "change" modifies the
    // *original* array, since the array was *not* copied
    // when passed as an argument:
    printf("Element at index 0: %d\n", my_array[0]);
  
    return 0;
}
  • However, you cannot do the same with structs
    • since passing strucut as parameter makes a new instance of that very struct (copies the struct)
    • so, to send structs to function calls, we must send the pointers
#include <stdio.h>
#include <string.h>

struct student {
    char first_name[20];
    char last_name[20];
    int year;
    float gpa;
};

/* This version of change() operates on a *copy* of struct s,
   not the original. This means that the print statement in main
   will print:
       first name if "Jo"
       GPA is 2.1
   ..since the original good_student is not modified by change().

====

void change(struct student s) {
    s.gpa = 4.0;
    strcpy(s.first_name, "Adam");
}
*/

/* Changes the values of a struct student's members. 
   This function operates on the *original* struct, rather
   than on a copy of the struct. */
void change(struct student *s) {
    strcpy((*s).first_name, "Adam");
    (*s).gpa = 4.0;
}

int main() {
    struct student good_student;
 
    strcpy(good_student.first_name, "Jo"); 
    good_student.gpa = 2.1;

    // Passing address of good_student:
    change(&good_student);
    
    printf("first name is %s\n",
                good_student.first_name);
    printf("GPA is %f\n", good_student.gpa);
  
    return 0;
}

Pointers to Structs

  • Anything we know about pointers, applies to structs as well
    • declate pointers to point to struct
    • change structs through their pointers
    • pass pointers to structs as functions
#include <stdio.h>
#include <string.h>

int main() {
    struct student {
        char first_name[20];
        char last_name[20];
        int year;
        float gpa;
    };
  
    struct student s;

    // Cannot be dereferenced until it points to
    // allocated space:
    struct student *p;
  
    // Initialize the members of s:
    strcpy(s.first_name, "Jo");
    strcpy(s.last_name, "Smith");
    s.year = 2;
    s.gpa = 3.2;
  
    // p now points to the address of struct student s:
    p = &s;

    // Dereference p to get the struct, then use the
    // dot operator to access the "gpa" member:
    (*p).gpa = 3.8;

    p->year = 1;    // this is the same as (*p).year = 1;
    strcpy(p->first_name, "Henrick");
  
    printf("Name: %s %s\n",
           s.first_name, s.last_name);
    printf("Year: %d. GPA: %.2f\n", s.year, s.gpa);
  
    return 0;
}

Writing to Files

#include <stdio.h>

int main() {
    FILE *output_file;
    int error;
    int total = 50;
    float small_number = 0.125;
  
    output_file = fopen("myfile.txt", "w");
    if (output_file == NULL) {
        fprintf(stderr, "Error opening file\n");
        return 1;
    }
  
    fprintf(output_file, "This will be the first line in the file\n");
    fprintf(output_file, "The integer is %d\n", total);
    fprintf(output_file, "The small float number is %f\n", small_number);
  
    error = fclose(output_file);
    if (error != 0) {
        fprintf(stderr, "fclose failed\n");
        return 1;
    }

    return 0;
}

Putting it all together

#include <stdio.h>

int main() {
    FILE *scores_file, *output_file;
    int error, total;
    char name[81];

        fprintf(stderr, "Error opening input file\n");

    output_file = fopen("names.txt", "w");

        fprintf(stderr, "Error opening output file\n");

    while (fscanf(scores_file, "%80s %d", name, &total) == 2) {

    error = fclose(scores_file);
    if (error != 0) {
        fprintf(stderr, "fclose failed on input file\n");
        return 1;
    }

    error = fclose(output_file);
    if (error != 0) {
        fprintf(stderr, "fclose failed on output file\n");
        return 1;
    }

    return 0;
}

Low Level IO

  • not all files are text files
  • but we handle them similarly
    • output_file = fopen("testing.txt", "r")
    • output_file = fopen("testing.dat", "rb")
      • include that letter b
  • Writing to binary files
    • fwrite(const void *ptr, size_t size, size_t nmemb, FILE *stream)
      • if return 1: success
      • if return 0: failure?
    • const void *ptr: pointer to the data that we want to write to the file. This is typically the starting address of an array, but can also be a pointer to an individual variable if we want to write just one value.
    • size_t size: size of each element that we're writing to the file.
    • size_t nmemb: number of elements that we are writing to the file. For an individual variable, the third parameter is one. For an array, it's typically the number of elements in the array.
    • FILE *stream: file pointer to which we will write. That file pointer must refer to a stream open in binary mode.

Complier Toolchain

  • Compilation process happens in a single step
    • Compiler is any program that translates one language to another language
  • However gcc must work on many different systems (Linux, windows, etc)
  • Compiler looks like the following 
flowchart LR
	id1[Source Program]-->id2[Lexical Analysis]
	id2[Lexical Analysis]-->|get Token|id3[Syntax Analysis]
	id3[Syntax Analysis]-->|Next Token|id2[Lexical Analysis]
	id3[Syntax Analysis]-->|Abstract Syntax Tree|id4[Semantic Analysis]
	id4[Semantic Analysis]-->|Modified AST|id5[Code Generation]
	id6[Code Generation]-->|Assembly|id7[Executable Program]
  • you can get the assembly file of the program by simply running gcc -S helloworld.c
    • makes helloworld.s assembly file
  • The compiler runs in 3 phases
    • Frontend: translates the source code into a largely language independent intermediate representation
      • gcc transforms language into gimple and generic
      • think of them as AST
    • Middle End: optimizing your code.
    • Backend: translates the intermediate language into the aseembly language that the computer can run
      • produces assembly code, not .out file
      • must convert it to executable
      • this is where assembler comes in
  • Assembler
    • we can invoke the assembler directly by using the command as helloworld.s -o helloworld
    • makes an object file helloworld.o
    • to produce an executable, simply execute gcc helloworld.s
      • produces a.out
  • Now, we must link
    • the executable is only specific to type of machine, operating system, and even the configuration
  • Loader
    • executable must be loaded into memory when executed

C function prototypes

  • int fclose(FILE *stream)
    • parameters
      • stream - pointer to the FILE object that specifies stream to be closed
    • return value
      • if successful, return 0
      • if not, return EOF
  • char fgets(char *str, int n, FILE stream)
    • parameters
      • str - pointer to an array where string read is stored
      • n - maximum number of characters to be read (including final null character)
        • so, be careful, probably have to do fgets(s, len + 1, fp)
    • return value
      • if successful, returns str pointer
      • if not, NULL
  • FILE fopen(const char *file, const char *mode)
    • parameters
      • filename - This is the C string containing the name of the file to be opened.
      • mode - This is the C string containing a file access mode.
        • r : opens file for reading. File must exist
        • w: Creates an empty file for writing.
        • a: Appends to a file. Writing operations, append data at the end of the file. The file is created if it does not exist.
    • return value
      • if successful, returns FILE pointer
      • if not, returns NULL
  • size_t fread(void *ptr, size t size, size t nmemb, FILE *stream)
    • parameters
      • ptr - pointer to a block of memory
      • size - size in bytes of each element to be read
      • nmemb - number of elements, each one with a size of size bytes
      • stream - pointer to a FILE object that specifies an input stream
    • return value
      • if successful, total number of elements
      • if not, EOF
  • int fscanf(FILE *restrict stream, const char *restrict format, ...)
    • return value
      • if successful, total number of elements
      • if not, EOF
  • int fseek(FILE *stream, long offset, int whence)
    • parameters
      • stream − This is the pointer to a FILE object that identifies the stream.
      • offset − This is the number of bytes to offset from whence.
      • whence − This is the position from where offset is added. It is specified by one of the following constants −
    • constants
      • SEEK_SET: beginning of file
      • SEEK_CUR: current position of file
      • SEEK_END: end of file
    • return value
      • if successful, returns zero
      • if not, non zero value
  • size t fwrite(const void *ptr, size t size, size t nmemb, FILE *stream)
    • parameters
      • ptr − This is the pointer to the array of elements to be written.
      • size − This is the size in bytes of each element to be written.
      • nmemb − This is the number of elements, each one with a size of size bytes.
      • stream − This is the pointer to a FILE object that specifies an output stream.
    • return value
      • if successful, total number of elements
      • if not, error
  • Excerpt from strcpy/strncpy man page:
    • The strcpy() functions copy the string src to dst (including the terminating ‘\0’ character).
    • The strncpy() function copies at most n characters from src into dst. If src is less than n characters long, the remainder of dst is filled with ‘\0’ characters. Otherwise, dst is not terminated.
  • Excerpt from strstr man page:
    • The strstr() function finds the first occurrence of the substring needle in the string haystack. It returns a pointer to the beginning of the substring, or NULL if the substring is not found.
  • Excerpt from strchr man page:
    • The strchr() function locates the first occurrence of c (converted to a char) in the string pointed to by s. The terminating null character is considered to be part of the string; therefore if c is ‘\0’, the functions locate the terminating ‘\0’.
  • Excerpt from strcat man page:
    • The strcat() function appends the src string to the dest string, overwriting the terminating null byte (’\0’) at the end of dest, and then adds a terminating null byte.
